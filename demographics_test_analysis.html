Demographics vs Test Occurrences

Which demographic groups receive more tests?

Key Findings:
  • Older patients receive significantly more tests (avg 8.9 for <1940 vs 2.7 for 1990s)
  • Males receive more tests than females (8.2 vs 7.3 avg)
  • Heavy smokers have highest test frequency (9.2 avg)
  • Widowed patients receive most tests (8.6 avg)
  • American Indian patients receive most tests by race (6.2 avg)
